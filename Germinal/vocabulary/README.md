# Koto bounded canonical Vocabulary registry

This non-live infrastructure supports the user-approved Vocabulary-first gold-Card recovery. Japanese records and evidence remain in authenticated private release bodies; only schemas, validators, manifests, and safe audits may be public.

Identity is deterministic from a frozen canonical identity record containing lemma, reading, lexical category, and a stable sense key. Workers never mint IDs. Zero maintains the append-only identity ledger and reverse-checks every Card link.

The initial lexical evidence source is an official English JMdict snapshot under CC BY-SA 4.0. Derived registry data retains attribution and ShareAlike obligations. Deployment requires a regular update procedure. JMdict priority markers are not imported as Commonness or learner grading; Koto Difficulty remains separate.

Grammar items may receive canonical IDs when JMdict supplies an applicable grammatical sense. Punctuation and genuinely non-lexical segments remain unlinked with structured reasons.
