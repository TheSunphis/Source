# Full Expression Card prototype renderer

Zero-owned non-live renderer for one accepted Germinal Card. The public renderer contains no restricted Card payload. It takes a private compiled `card.json` and acceptance overlay and emits one self-contained HTML file with responsive layout, complete segment analysis, labelled colour cues, explicit-action Japanese device TTS, and mutually exclusive Recognised/Review controls.

Generated Card HTML remains in authenticated private draft-release bodies. This renderer does not write live `Expressions/`, modify `main`, package a release, or authorize scaling.
