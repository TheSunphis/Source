# GERMINAL terminology

The commissioning unit is a **Sentence**. A Sentence may contain one primary form and evidence-supported alternate forms.

- Unpublished agent output: Sentence proposal
- Passed commissioning record: Sentence
- Opened learner view: Full Sentence Card
- Twenty-five passed Sentences: Pack
- Four hundred proposed Sentences: Wave
- Failed or unsupported proposal: Quarantined Sentence

Agents must use Sentence/Sentences in reports and status metadata.
