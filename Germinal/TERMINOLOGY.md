# GERMINAL terminology

The commissioning unit is a **Expression**. A Expression may contain one primary form and evidence-supported alternate forms.

- Unpublished agent output: Expression proposal
- Passed commissioning record: Expression
- Opened learner view: Full Expression Card
- Twenty-five passed Expressions: Pack
- Four hundred proposed Expressions: Wave
- Failed or unsupported proposal: Quarantined Expression

Agents must use Expression/Expressions in reports and status metadata.
