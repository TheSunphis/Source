# GERMINAL terminology

## Continuity rule

**Expression is the new name for the former Family.** This is a terminology change, not a new corpus unit, grouping method, candidate pool, schema ontology, or Card design.

An Expression retains the established Family model: one coherent learner item containing a primary form, evidence-supported alternate forms, Library data, the complete opened Card, conversation support, distinctions, verification, provenance, and analysis. Existing machine-facing keys such as `familyId`, `formId`, family classes, and family-schema references remain valid. Agents must not rename or redesign those internal contracts unless Zero supplies an explicit versioned migration.

The current Germinal transport envelopes divide work and carry proposals/reviews. They do not replace the established Family data model.

## Names

- Learner-facing and agent-facing unit: Expression
- Internal established data unit: Family-compatible Expression
- Unpublished agent output: Expression proposal
- Passed commissioning record: Expression
- Opened learner view: Full Expression Card
- Compact Library item: Library Result Tile
- Primary or alternate realization: Form
- Twenty-five passed Expressions: Pack
- Failed or unsupported proposal: Quarantined Expression

Agents use Expression/Expressions in learner-facing text, status, and reports while preserving required legacy machine keys exactly.
