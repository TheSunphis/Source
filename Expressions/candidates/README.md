# Expression candidates

This directory contains **non-production source candidates** extracted reproducibly from licensed datasets. Candidate records are not Koto expression families, do not have Koto Difficulty ratings, and must not be shown to learners.

A candidate can become a production family only after:

1. source and licence verification;
2. cross-source and cross-entry deduplication;
3. an inclusion decision under `review-policy.json`;
4. naturalness, meaning, reading, register, social-use, difficulty, and substitution review;
5. completion of the rich expression-family fields; and
6. final publication approval.

Candidate pack order is for editorial triage only. It is not a learner-facing Commonness score or Difficulty rating.
