# Koto Shogun artwork

Responsive artwork for Koto's **Shogun: Citadel of Command** visual style. Koto loads these files from an immutable public GitHub commit and keeps selected variants in the browser Cache Storage API; the application package does not bundle a second image copy.

The images were exported from the audited Koto application artwork at commit `ee2880520c5ff4d0e12afffc7645e01f0ecd371b`. The adjacent manifest records byte lengths, SHA-256 hashes, and pixel dimensions.
